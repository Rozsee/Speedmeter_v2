# Speedmeter_v2
2nd version of Speedmeter used in my old Toyota.
HW:  
  - RPI2040 Zero board (waveshare)
  - Sparkfun OBD to UART breakout board
  - 2x20 character alphanumeric VFD display from an old cashmachine

SW: MicroPython

Features:
  - Continous polling of speed and motor rpm values
  - Speed value is displayed by special big digits (idea source: https://hackaday.com/2023/04/07/spice-up-the-humble-16x2-lcd-with-big-digits/)
  - Manual brightness adjustment
  - Housing and all mechaincs is home designed and printed (PETG)
